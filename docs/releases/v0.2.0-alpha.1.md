# VulnScribe 0.2.0-alpha.1 — Preview Candidate Notes

**Status:** candidate under review; not a published release.
**Package metadata version:** `0.2.0a1` (PEP 440).
**Intended GitHub tag:** `v0.2.0-alpha.1` (not created).

## Intended user-facing changes

- Local browser workspace for source-code and raw HTTP-response scans.
- File-to-editor loading in the browser, with size limits and no automatic submission.
- Review view for candidate findings, severity estimates, confidence, rule IDs, source locations, evidence, remediation, references, and warnings.
- JSON download from the displayed scan result and Markdown export through the existing report generator without rescanning.
- Same-origin static assets, safe DOM text rendering, and restrictive content security policy on the UI document.
- Structured GitHub bug-report form with warnings against posting secrets, source code, tokens, or private reports.
- Version displayed from the API health endpoint.
- Python AST-based direct `eval()`/`exec()` detection and corrected HSTS regression fixture are included in the merged baseline.

## Safety and privacy boundaries

- Designed for local, loopback use. This candidate is not hardened for public or multi-user deployment.
- No submitted code is executed, no live host is contacted, and no artifact is uploaded to a third-party service by the UI.
- Findings remain deterministic candidates for human review, not confirmed vulnerabilities.
- No automatic CVSS scoring or measured precision/recall claim.
- HSTS is evaluated only when the caller explicitly identifies transport as HTTPS.
- GitHub issues can be public. Users must remove secrets, sensitive code, private raw responses, and identifying diagnostics before posting.

## Candidate acceptance gate

Before publication, verify the exact candidate commit using the supported local environment: full pytest suite, Ruff, whitespace checks, packaging/install validation, UI/API/CLI journey tests, and inspection of the built distribution to ensure static assets are included. Record the exact commit SHA, test results, warnings, artifact provenance, and approver. Do not publish if these checks have not been completed.
